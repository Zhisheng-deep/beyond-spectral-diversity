# Data

This folder holds the data used by the scripts of the repository. The hyperspectral images and species maps are real data for two example plots of the study, one under grazing and one under fencing.

## `species_code.csv`

DK-CAT assigns each pixel a species. As GeoTIFF pixel values are numeric, each species is stored in the species maps as an integer code. This table lists the codes and the species they stand for.

| Column | Description |
| --- | --- |
| `code` | integer code of the species in the species maps |
| `species` | scientific name, as in Table 1 of the paper |

Pixels removed by the radiometric filtering (soil and shaded pixels) are stored as NoData.

## `species_map/`

DK-CAT species maps of the two example plots, single-band GeoTIFFs at 2 cm pixel size, as used in the paper. Each file covers one 1.5 m × 1.5 m plot and is named `<unit>_<plot>_species_map.tif`, where `<unit>` is the management unit and `<plot>` the plot within it.

| File | Management regime |
| --- | --- |
| `49_15_species_map.tif` | grazing |
| `79_2_species_map.tif` | fencing |

These maps are the input of `../2_dominance_metrics`.

## `hyperspectral/`

UAV hyperspectral images of the same two plots after the processing described in Section 2.3 of the paper: 215 bands from 450 to 895 nm, brightness-normalized, at 2 cm pixel size (WGS 84 / UTM zone 50N). Each 1.5 m × 1.5 m plot has a multi-band GeoTIFF, `<unit>_<plot>_hyperspectral.tif`, and an ENVI header, `<unit>_<plot>_hyperspectral.hdr`, that lists the band wavelengths. Pixels removed by the radiometric filtering (soil and shaded pixels) are stored as NoData.

| Files | Management regime |
| --- | --- |
| `49_15_hyperspectral.tif`, `49_15_hyperspectral.hdr` | grazing |
| `79_2_hyperspectral.tif`, `79_2_hyperspectral.hdr` | fencing |

These images are the input of `../1_classification`, which produces the species maps in `species_map/`.

## `simulated/`

Simulated data from which the scripts in `../3_statistics_figures` run, generated by `../3_statistics_figures/simulate_data.R` with a fixed seed. They follow the sampling design of the paper, 10 management units (6 under grazing and 4 under fencing) with 47 plots of 1.5 m × 1.5 m, but come from a random model: they demonstrate the analytical workflow and reproduce the layout of the figures, but the statistical results obtained from them differ from those of the paper.

| File | Sampling units | `Scale` | n |
| --- | --- | --- | --- |
| `analysis_table.csv` | 0.5 m × 0.5 m quadrats, 1 m × 1 m subplots and 1.5 m × 1.5 m plots | `0.5m`, `1m`, `1.5m` | 423, 188, 47 |
| `multiscale_table.csv` | 0.5 m × 1 m and 1 m × 1.5 m windows within the plots, and pooled plots formed from all combinations of two and three plots within a management unit | `0.5x1m`, `1x1.5m`, `pool2`, `pool3` | 564, 188, 92, 94 |

| Column | Description |
| --- | --- |
| `Scale` | spatial scale (see above) |
| `Management` | management regime, `grazing` or `fencing` |
| `Unit`, `Plot`, `Plot15` | management unit, plot within the unit, and `<unit>_<plot>`; empty for pooled plots |
| `Window` | sampling unit within the plot: quadrats `1`–`9` and subplots `1`–`4` as in `../2_dominance_metrics`, `0` for the plot, `H` and `V` followed by a number for the horizontal and vertical windows of `0.5x1m` and `1x1.5m`; for pooled plots, the plots they contain |
| `member_plots` | plots that make up the sampling unit, given as `Plot15` and separated by `;`: the plot containing the window, or the two or three plots that form a pooled plot (`multiscale_table.csv` only) |
| `n_plots` | number of plots in `member_plots` (`multiscale_table.csv` only) |
| `Observed_SR`, `Observed_Visible_SR` | observed full-community and sunlight-exposed species richness |
| `DL_SR` | species richness predicted by deep learning (DL-SR) |
| `SSR_km_z` | spectral species richness (SSR) from k-means clustering of z-scored reflectance |
| `DL_Top1` … `DL_Top123` | dominance metrics from the deep learning species maps |
| `SC_Top1` … `SC_Top123` | dominance metrics from the spectral clusters |
| `OB_Top1` … `OB_Top123` | dominance metrics from the field species abundance |
| `Turnover` | species turnover; undefined at 0.5 m |
| `Rare_Species_Ratio` | rare species ratio |
| `FVC` | fractional vegetation cover |
| `Height_Mean`, `Height_CV` | mean canopy height and canopy height CV |
| `Intra_Species_SDiv` | intra-species spectral diversity (SDiv) |
| `CV`, `CHA`, `Rao'S Q` | coefficient of variation, convex hull area and Rao's quadratic entropy |
| `Observed_Shannon`, `DL_Shannon`, `SC_Shannon` | Shannon–Wiener index observed in the field, from the deep learning species maps and from the spectral clusters |

The metrics are defined as in Table S1 of the paper, and the dominance metrics as in `../2_dominance_metrics`.
