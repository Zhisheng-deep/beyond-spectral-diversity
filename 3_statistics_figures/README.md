# 3. Statistical analyses and main-text figures

This folder contains one R script for each main-text figure of the paper (Fig. 4–12). Each script runs the statistical analysis behind its figure and draws the figure. Functions shared by several scripts are in `functions.R`.

## Data

The scripts run on simulated data with the sampling design of the paper, generated by `simulate_data.R` and provided in `../data/simulated` (columns are described in `../data/README.md`). The simulated data come from a random model: they demonstrate the analytical workflow and reproduce the layout of the figures, but the statistical results obtained from them differ from those of the paper.

## Scripts

| Script | Figure | Analysis |
| --- | --- | --- |
| `Fig04_direct_SR.R` | Fig. 4 | ordinary least squares regressions of observed full-community species richness (SR) on DL-SR and SSR |
| `Fig05_visible_full_SR.R` | Fig. 5 | regressions of observed sunlight-exposed and full-community SR on DL-SR and SSR, and mean absolute error |
| `Fig06_dominance_models.R` | Fig. 6 | multiple regressions of observed SR on the dominance metrics retained after collinearity screening, with 95% cluster-bootstrap intervals |
| `Fig07_single_metrics.R` | Fig. 7 | regressions of observed SR on each dominance metric alone |
| `Fig08_correlation_fan.R` | Fig. 8 | Spearman correlations with observed SR and the Shannon–Wiener index, with Benjamini–Hochberg adjusted P values |
| `Fig09_cross_validation.R` | Fig. 9 | adjusted R² and leave-one-unit-out cross-validated R² on all observations and for one observation per plot |
| `Fig10_extended_scales.R` | Fig. 10 | regressions of observed SR on DL-SR, DL-Top123, SSR and SC-Top123 at seven spatial scales, with 95% cluster-bootstrap intervals |
| `Fig11_mixed_models.R` | Fig. 11 | linear mixed models: sequential decomposition and hierarchical partitioning of the marginal R² |
| `Fig12_stratified.R` | Fig. 12 | regressions of observed SR on DL-SR and SSR in the low and high strata of four ecological factors |
| `simulate_data.R` | — | generates the simulated data in `../data/simulated` |
| `functions.R` | — | shared functions (data reading, figure style, regression, collinearity screening, cluster bootstrap) |

All scripts read `analysis_table.csv`; `Fig10_extended_scales.R` also reads `multiscale_table.csv`. The header of each script lists its steps, input columns and output files.

## Usage

Run each script from this folder, for example

    Rscript Fig04_direct_SR.R

By default, each script reads the simulated data from `../data/simulated` and writes its output to `output/`. Other paths can be given as arguments:

    Rscript Fig04_direct_SR.R [data_file] [output_dir]
    Rscript Fig10_extended_scales.R [data_file] [multiscale_file] [output_dir]

In RStudio, set the working directory to this folder and source the script. Each script runs independently of the others, and the complete set runs in a few minutes.

`Rscript simulate_data.R` regenerates the simulated data with a fixed seed (about two minutes).

## Output

Each script writes to `output/` the statistics of its figure as CSV tables and the figure as a TIFF file (600 dpi, LZW compression), together with its single panels for figures with several panels. Parts a and b of Fig. 5, Fig. 11 and Fig. 12 are written as separate files.

## Requirements

R 4.4.2 with the packages *ggplot2* (4.0.0), *cowplot* (1.1.3), *ragg* (1.3.3), *patchwork* (1.3.2), *dplyr* (1.1.4), *tidyr* (1.3.1), *scales* (1.4.0), *car* (3.1.3), *lme4* (1.1.35.5), *lmerTest* (3.1.3), *MuMIn* (1.48.11) and *glmm.hp* (1.0.0).
